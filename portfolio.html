Recent Projects

Project Skill-Bridge

SkillBridge is a full-stack Learning Management System (LMS) developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js). The platform connects students, tutors, and administrators through dedicated dashboards and role-based authentication. It supports course management, structured learning content, and course navigation. The frontend is built with React.js, Vite, Tailwind CSS, and Axios, while the backend uses Express.js, MongoDB, and REST APIs. Security and reliability features include JWT authentication, password hashing, input validation, CORS, Helmet, API rate limiting, request logging, and centralized error handling.
